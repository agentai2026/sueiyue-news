# 岁月实时新闻

岁月实时新闻是一个热点聚合页：把国内各平台正在热议的内容收进同一屏，让你不用来回切换，就能看见今天发生了什么。

网站：https://news.sueiyue.cn

## 这是什么

每天的热点散落在微博、知乎、B 站、头条、财经媒体、科技社区等很多地方。这里把这些热榜做成一张张卡片，并排摆在一起。你看到的是各源此刻的标题、热度和更新时间，点进去才去原网站读全文。

它不是自写新闻的媒体，也不替代原平台。它只做一件事：**把「现在什么火」摊开给你看。**

## 你能在这里做什么

- 一页浏览多家热榜，快速扫过今天的舆论和行业动态
- 打开某个来源的官网，或点进单条新闻
- 给常用站点打星，方便下次先看它们
- 看顶栏的可用站点 / 失效站点，了解当前哪些源正常、哪些暂时拉不到
- 手动刷新，把卡片更新到最新一轮
- 在「关于」里留言：建议、问题、想增加的源，都可以说

站点有进站密码，主要给自己和受邀的人用，不是面向全网随便逛的公共门户。

## 它不做什么

- 不登录账号，不把关注同步到云端，星标只记在你这台设备的浏览器里
- 不生产稿件、不做立场综述，标题来自各平台热榜本身
- 个别源会因对方网站限制而暂时失效，这很正常
